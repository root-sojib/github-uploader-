GitHub Repo ও Bulk Upload Tool

মোবাইল থেকে repository তৈরি করে ZIP, folder বা একাধিক file একসাথে upload করুন।

নিরাপত্তা: GitHub token কাউকে দেবেন না

১) GitHub সংযোগ

Classic token ব্যবহার করলে repository তৈরি/আপলোডের জন্য সাধারণত repo scope দরকার। Fine-grained token-এ target repository-র Contents: Read and write এবং repository তৈরি করার উপযুক্ত permission লাগতে পারে। যত কম permission সম্ভব দিন।

Owner/username Token থেকে স্বয়ংক্রিয়ভাবে শনাক্ত হবে; আলাদা করে লিখতে হবে না।

নতুন repository তৈরি করার সময় README দিয়ে initialize করা হয়, যাতে main branch তৈরি থাকে। আগে থেকে থাকা repository-তেও upload করা যাবে।

২) ফাইল বেছে নিন

এখনো কোনো file নির্বাচন করা হয়নি। একাধিক input থেকেও file যোগ করা যাবে।

Folder input সব ব্রাউজারে সমানভাবে কাজ নাও করতে পারে। ZIP ফাইলের ভেতরের folder structure রাখা হবে। একই path একাধিকবার থাকলে শেষের file-টি ব্যবহার হবে।
